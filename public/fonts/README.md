# Noto Sans CJK

`NotoSansCJKsc-Regular.otf` is the unmodified Simplified Chinese Regular face from
[Noto Sans CJK 2.004](https://github.com/notofonts/noto-cjk/releases/tag/Sans2.004).
It also contains Traditional Chinese, Japanese kana, and Korean Hangul glyphs.
Shared Han glyphs use Simplified Chinese forms.

Source: https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

License: SIL Open Font License 1.1, included in `OFL.txt`.

The font is served locally and loaded only when visible badge text contains a
character missing from DejaVu Sans. No external font service is required.
